# Hayley 的健康管家

以手機優先設計的個人健康管理 App，整合每日步數、GPS 步行距離、活動時間、熱量基準與飲食營養紀錄。所有資料僅儲存在瀏覽器 `localStorage`，沒有帳號、沒有後端，也不會上傳個人紀錄。

## 技術架構

- Vite + React + TypeScript
- Tailwind CSS v4（`@tailwindcss/vite` + `@import "tailwindcss";`，無 `tailwind.config.js`）
- lucide-react 圖示
- localStorage 本機儲存
- 衛福部食藥署 TFDA 食品營養成分開放資料（建置時同步、執行時離線）

## 四大功能

1. **動能**：每日步數、目標達成率、近 7 天趨勢；可手動新增、重設與調整目標。
2. **健康**：BMI 計算與衛福部體位分類、BMR、TDEE、理想體重範圍與熱量建議。
3. **飲食**：以真實台灣在地食材搜尋與查詢營養成分，依份量計算熱量與營養素，加入今日餐點紀錄；所有變更立即更新。
4. **設定**：性別、年齡、身高、體重、活動強度；資料來源、隱私說明與清除本機資料。

首次開啟會顯示免責聲明 Modal，點選「我已閱讀並了解」後才會進入 App。

## 飲食資料來源

- 資料集：食品營養成分資料集（資料集編號 8543）
- 提供機關：衛生福利部食品藥物管理署
- 授權：政府資料開放授權條款－第 1 版
- 官方頁面：<https://data.gov.tw/dataset/8543>
- 更新頻率：每 3 個月
- 本專案資料版本：2026-10-05（共 2,213 種食物）

營養數值為每 100 公克可食部分。部分食材的特定營養素未檢驗，畫面以 `—` 表示，計算每日總和時以 0 計入。資料僅供參考，不能取代專業醫療建議。

### 更新營養資料

```bash
npm run sync:nutrition
```

腳本會下載官方 ZIP、解壓縮、將「一列一營養素」正規化為「一筆一食物」，並輸出：

- `src/data/tfda-foods.json`
- `src/data/tfda-meta.json`

原始 ZIP 會快取在 `.cache/tfda/`（不進版控）。強制重新下載：

```bash
npm run sync:nutrition -- --refresh
```

> App 執行時不會連線下載 130 MB 的原始資料；資料已精簡並打包進前端，因此搜尋與計算可離線完成。若官方資料更新，需由開發者重新執行同步腳本並部署新版本。

## 本機資料與隱私

| Key | 內容 |
| --- | --- |
| `health_app_profile_v1` | 生理數據 |
| `health_app_steps_v1` | 每日步數與目標 |
| `health_app_meals_v1` | 飲食紀錄（含份量、餐別與 TFDA 食物編號） |
| `health_app_disclaimer_v1` | 免責聲明同意狀態 |

- 每個人使用自己的手機時，資料只存在該裝置的瀏覽器。
- 食物搜尋、營養計算與紀錄新增／刪除都在本機即時完成。
- 清除瀏覽器資料或更換裝置後，紀錄無法復原。
- 沒有帳號、沒有伺服器、沒有追蹤碼。

## 注意事項

- 步數由本機手動紀錄；首次開啟提供示範數據，可自行新增或重設。
- 飲食紀錄以 TFDA 食材資料計算；實際營養含量會因品種、烹調方式與份量估算而異。
- 六大類食物卡僅顯示《每日飲食指南》建議量，不代表本次飲食實際攝取份數。
- 本應用程式所提供之健康資訊與營養建議僅供參考，不能取代專業醫療診斷、建議或治療。在做出任何醫療決定前，務必要諮詢合格的醫療專業人員。
